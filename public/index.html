What is Pipelining?

Pipelining allows a CPU to process multiple instructions by overlapping different stages of instruction execution to reduce overall processing time.

⚡ Pipelining vs Non-Pipelining

🐢 Non-Pipelining

In non-pipelining, one instruction completes all its stages before the next instruction begins. This increases the total execution time.

🚀 Pipelining

Pipelining allows multiple instructions to be processed simultaneously by overlapping different stages of execution, reducing the overall processing time.

Understanding CPU Pipelining

CPU pipelining divides instruction execution into stages, allowing multiple instructions to be processed simultaneously at different stages. This results in faster processing.

Pipeline Stages

  • Fetch – Instruction Fetch
  • Decode – Instruction Decode
  • AG – Address Generation
  • Execute – Perform Operation
  • Store – Store Result

Performance Formulas

Non-pipelined cycles = Instructions × Stages

Ideal pipelined cycles = Instructions + Stages − 1

Speedup = Non-pipelined cycles ÷ Pipelined cycles
